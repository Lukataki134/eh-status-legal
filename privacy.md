# Datenschutzerklärung für EH Status

**Stand: 20. Oktober 2026**

## 1. Verantwortlicher

EH Status ist ein unabhängig entwickelter Discord-Bot. Für Fragen zum Datenschutz wenden Sie sich bitte über einen offiziellen Support-Kanal an den Entwickler, sofern ein solcher bereitgestellt wird.

## 2. Welche Daten werden gespeichert?

Die aktuelle Version von EH Status kann folgende Daten lokal in einer Datei namens `server_ids.json` speichern:

- Die ID des Discord-Servers, auf dem der Befehl verwendet wurde.
- Die vom Nutzer eingegebene Server-ID für Notruf Hamburg.

Diese Angaben werden gespeichert, damit die Konfiguration des Bots für den jeweiligen Discord-Server erhalten bleibt.

## 3. Wo werden die Daten gespeichert?

Die genannten Angaben werden in einer lokalen JSON-Datei im Projektverzeichnis des Bots gespeichert. Die tatsächliche Speicherung und mögliche weitere Datenverarbeitung hängen davon ab, wo und wie der Bot betrieben wird.

## 4. Weitergabe von Daten

Die aktuelle Konfiguration ist dafür vorgesehen, die oben genannten Angaben lokal zu speichern. Eine Weitergabe an Dritte ist anhand der bisherigen Implementierung nicht vorgesehen. Das kann sich ändern, wenn später externe Dienste eingebunden werden.

## 5. Speicherdauer und Löschung

Die gespeicherten Konfigurationsdaten bleiben erhalten, bis sie aus der Datei gelöscht oder die Datei entfernt wird. Für eine Löschanfrage wenden Sie sich bitte über einen offiziellen Support-Kanal an den Entwickler, sofern einer bereitgestellt wird.

## 6. Änderungen dieser Datenschutzerklärung

Diese Datenschutzerklärung kann aktualisiert werden, wenn sich die Funktionen oder die Datenverarbeitung von EH Status ändern.

## 7. Kontakt

Bei Fragen zum Datenschutz wenden Sie sich bitte über einen offiziellen Support-Kanal an den Entwickler, sofern ein solcher bereitgestellt wird.
